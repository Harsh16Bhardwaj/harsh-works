# Work Console

The Work Console comes before Project Gallery.

Purpose:

> Show what Harsh actually does.

## Lanes

### ML + Data

Thesis:

EDA, feature decisions, model validation, metrics, and learning-by-case-study.

Outputs:

- notebooks
- model reports
- EDA guides
- validation notes
- metric decisions
- ML Lab case studies

Projects:

- ML Atlas
- FIFA Predictor
- RoomSense / sensor tasks
- Insurance regression

### Full-stack Products

Thesis:

Auth, DB, dashboards, queues, deployment, and operator-facing workflows.

Outputs:

- web apps
- dashboards
- API routes
- queue flows
- data models
- deployment pipelines

Projects:

- NameFrame
- PersonalCloud
- JEDI
- Placement Calendar

### Automation + Learning Systems

Thesis:

Scrapers, agents, checklists, public notes, and repeatable workflows.

Outputs:

- scrapers
- automation scripts
- Codex skills
- structured notes
- resource shelves
- build logs

Projects:

- ClipHawk
- Codex skills/workflows
- Field Notes
- Sheets/Checklists/Materials

## Visual direction

Three vertical lanes. Each lane has:

- title
- short thesis
- current work
- output types
- related projects
- proof artifacts

## Interaction

- Hover/selection highlights related projects.
- On mobile, lanes become stacked accordions.
- Each lane can link to filtered Project Gallery.
