# GitHub Map Clusters

## ML Lab

For EDA, classification, regression, model validation, data cleaning, feature engineering, metric tradeoffs, and ML study artifacts.

Possible projects:

- ML Atlas
- FIFA Predictor
- RoomSense / sensor classification tasks
- Insurance regression tasks
- EDA guides/notebooks

## Full-Stack Systems

For serious app/product systems with auth, DB, APIs, UI, queues, dashboards, and deployment.

Possible projects:

- NameFrame
- PersonalCloud
- JEDI
- Placement Calendar
- The Citadel

## Automation

For scrapers, batch workers, certificate generation, Playwright/Selenium, agents, and workflow accelerators.

Possible projects:

- ClipHawk
- NameFrame automation pieces
- Codex workflows
- Appium/cloud-phone automation

## Learning Repos

For structured public learning trails.

Examples:

- DSA notes
- SQL practice
- OS/core subject sheets
- ML algorithm pages
- agent reading plans

## Tiny Builds

For small useful or weird experiments.

Examples:

- UI experiments
- weekend apps
- mini utilities
- proof-of-concept builds

## Archived / Hidden

For old, weak, duplicate, incomplete, or not-portfolio-worthy repos.

Rule:

Hidden repos can still exist on GitHub; they just should not be visually promoted.
