# Animation Rules

## Core rule

One dominant animation idea per section.

## First five sections

### Hero

Dominant animation:
Sakura-petal scene + identity reveal.

### About

Dominant animation:
Builder thesis / proof-trail flow reveal.

### GitHub Map

Dominant animation:
Repo clusters forming and filtering.

### Work Console

Dominant animation:
Three lanes booting like a console.

### Project Gallery

Dominant animation:
Case files/cards reveal and expand.

## Do

- use animation to guide attention
- preserve readability
- support reduced motion
- reduce motion on mobile
- keep hover effects subtle
- use smooth layout transitions for project expansion

## Don't

- animate every element differently
- use random bouncing
- create scroll hijacking
- make text hard to read
- run heavy effects forever
- let 3D dominate content
