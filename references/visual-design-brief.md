# Visual Design Brief

## Active Source

Use `references/portfolio-image-system-guide.md` as the long-form source for the current image system.

## Theme

Minimal Dune-inspired sci-fi editorial personal platform.

The site should feel like one continuous world: desert horizon, huge moon, observation base, dark teal cosmic chamber, light editorial case files, materials archive, orbitals, and a dark planet footer.

## Feeling

- technical
- calm
- sharp
- proof-backed
- spacious
- monumental
- slightly poetic
- not corporate
- not childish

## Visual metaphors

- desert field record
- observation deck
- cosmic work chamber
- technical field journal
- ML lab wall
- project case files
- materials archive
- orbital wishlist
- planetary footer heatmap

## Color direction

Use as direction, not strict requirement:

- warm desert sections: rose, peach, mauve, violet, sand, indigo
- cosmic work sections: dark teal, blue-black, Milky Way haze, pale cyan
- editorial archive sections: ivory, pale sand, deep charcoal typography
- footer: dark planet surface with sun flare and readable heatmap overlay

## Typography direction

- large confident hero type
- readable body text
- mono labels for system chips/status
- avoid too many font families
- hierarchy > decoration

## Layout direction

- spacious hero
- dense but controlled proof sections
- cards with strong hierarchy
- bento/project layouts only where useful
- mobile-first stacking

## Signature visual ideas

### Hero

Lone figure or identity-scale desert/moon image, minimal copy, large negative space.

### About

Observation deck / desert base interior explaining builder thesis.

### Work Console

Dark teal cosmic observatory, potentially two seamless stacked images for longer work records.

### Project Gallery

Light editorial archive/case-file layout. Prioritize readability over cinematic background.

### Footer

Dark planet and flare with GitHub heatmap plus minimal links.
