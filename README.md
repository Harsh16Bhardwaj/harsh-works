# Harsh Bhardwaj Personal Platform

A dark minimalist personal platform built with Next.js, React, Three.js, and animejs.

The site is meant to feel like Harsh's own workspace: builds, notes, experiments,
GitHub proof trails, active lanes, and selected case files in one place.

## Commands

```bash
npm install
npm run dev
npm run build
npm run start
```

The landing page uses a responsive Three.js sakura/rose petal scene for the hero and animejs for section reveal motion. Content is kept in editable local data files under `src/data/`.
